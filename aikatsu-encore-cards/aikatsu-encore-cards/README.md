# AIKATSU ENCORE! CARD COLLECTION

아이카츠 앙코르! 카드 판매용 **카드 선택 웹사이트**입니다.
손님은 카드를 눌러 고르고, 고른 카드를 한 장의 PNG 이미지로 저장해 보낼 수 있습니다.

- React 19 + TypeScript + Vite + Tailwind CSS v4
- 이미지 합치기: HTML Canvas API (브라우저 안에서 처리, 서버 전송 없음)
- 카드 데이터: IndexedDB / 선택 상태·설정: LocalStorage

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버 → http://localhost:5173
npm run build      # 배포용 빌드 → dist/
npm run preview    # 빌드 결과 미리 보기
```

`npm run dev`를 실행하면 터미널에 `Network: http://192.168.x.x:5173` 주소도 함께 나옵니다.
같은 Wi-Fi에 연결된 휴대폰에서 이 주소로 접속하면 모바일 화면을 바로 확인할 수 있습니다.

## 카드 사진 넣는 방법 (2가지)

### 1) 기본 카드: `src/assets/cards/` 폴더에 넣기 — 손님에게 보여줄 카드는 이 방법으로

JPG / JPEG / PNG / WEBP 파일을 이 폴더에 넣으면 사이트를 열 때 자동으로 카드 목록에 추가됩니다.
빌드해서 배포하면 **모든 방문자에게** 같은 카드가 보입니다.

파일명을 `카드번호_카드이름.jpg` 형식으로 지으면 번호와 이름이 자동으로 입력됩니다.

```
src/assets/cards/
  AE01-001_반짝이는 리본 코디.jpg   → 번호 "AE01-001", 이름 "반짝이는 리본 코디"
  AE01-002_스타라이트 드레스.png
  my-card.webp                      → 번호 없음, 이름 "my-card"
```

### 2) 관리 화면에서 업로드 — 지금 쓰는 브라우저에만 저장

상단의 **관리** 버튼 → 카드 추가에서 사진을 여러 장 한 번에 올릴 수 있습니다.
업로드한 카드는 그 브라우저의 IndexedDB에 저장되므로, 브라우저를 다시 열어도 남아 있지만
**다른 기기·다른 방문자에게는 보이지 않습니다.**
(서버 없이 동작하도록 한 설계입니다. 모든 방문자가 보게 하려면 1번 방법을 쓰세요.)

관리 화면에서 할 수 있는 일

- 카드 이름·번호 수정, 이미지 교체
- 표시 순서 변경 (화살표 버튼, PC에서는 끌어서 놓기)
- 개별 삭제 / 체크해서 여러 장 일괄 삭제 (삭제 전 확인창)
- 기본 카드(폴더 카드)를 삭제해도 파일은 남아 있으므로 ‘삭제한 기본 카드 복원’으로 되살릴 수 있습니다.

## 화면 구성

| 탭 | 기능 |
| --- | --- |
| 카드 갤러리 | 검색(이름·번호), 정렬, 카드를 눌러 선택/해제, 전체 선택·전체 해제, 선택만 보기 |
| 선택 카드 | 선택한 카드 모아보기, 개별 해제, 순서 변경(화살표·드래그·번호순/이름순 등) |
| 이미지 저장 | 한 줄 카드 수(3~6장), 간격, 여백, 배경색, 이름·번호 표시, 배치 순서 설정 → 실시간 미리보기 → PNG 다운로드 |
| 카드 관리 | 카드 추가·수정·삭제·순서 변경 |

선택한 카드와 저장 설정, 현재 탭은 새로고침해도 유지됩니다.

## 이미지 저장 동작

- 미리보기는 가벼운 썸네일로 빠르게 그리고, **다운로드할 때는 원본 이미지**로 다시 그립니다.
- 카드 폭은 선택한 카드 원본 폭(중앙값)을 그대로 사용하므로 화질이 떨어지지 않습니다.
  카드 비율은 원본 그대로이며 잘리거나 늘어나지 않습니다.
- 모든 이미지를 다 불러온 뒤에 그리고, 6장마다 브라우저에 쉬는 틈을 주어 카드가 많아도 화면이 멈추지 않습니다.
- 카드가 아주 많으면 브라우저 캔버스 한계(iPhone 약 1,600만 화소)에 맞춰 자동으로 조금 줄여서 저장하고, 화면에 안내합니다.
- 파일명: `aikatsu_selection_YYYYMMDD.png`
- 선택한 카드 수가 한 줄 카드 수보다 적으면 빈 칸 없이 그 수만큼만 열을 만듭니다.

## 배포

`npm run build` 후 생성되는 `dist/` 폴더를 Netlify, Vercel, GitHub Pages 등에 올리면 됩니다.
(`vite.config.ts`의 `base: './'` 덕분에 하위 경로에 올려도 동작합니다.)

> 관리 화면에는 비밀번호가 없습니다. 서버가 없어 업로드한 카드는 그 사람의 브라우저에만 저장되므로
> 방문자가 관리 화면을 열어도 실제 판매 목록(폴더 카드)은 바뀌지 않습니다.

## 폴더 구조

```
src/
  assets/cards/        기본 카드 이미지 폴더
  lib/db.ts            IndexedDB 저장소
  lib/localCards.ts    폴더 이미지 자동 불러오기 (import.meta.glob)
  lib/sheet.ts         Canvas 이미지 시트 생성·다운로드
  lib/image.ts         이미지 로드, 썸네일 생성
  hooks/useCards.ts    카드 목록 상태와 추가·수정·삭제·순서 변경
  hooks/useSelection.ts 선택 상태 (LocalStorage 유지)
  views/               갤러리 / 선택 카드 / 이미지 저장 / 관리 화면
  components/          공통 UI
```
